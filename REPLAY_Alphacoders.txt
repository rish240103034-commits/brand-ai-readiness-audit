TEST_STEPS:   (copy-paste, in order, from a clean checkout)
------------------------------------------------------------
  1. Clone and pin the exact Round 3 engine:
        git clone https://github.com/rish240103034-commits/brand-ai-readiness-audit.git
        cd brand-ai-readiness-audit
        git checkout v2.7.0
     (Windows only:)  set PYTHONUTF8=1

  2. The prompt given to the agent (Claude Code), verbatim:
        Run our Round 3 marketplace audit on https://www.samsung.com using the
        submitted v2.7.0 engine by executing exactly:
          python skills/audit-orchestrator/scripts/run_audit.py https://www.samsung.com --out report.json
          python skills/audit-orchestrator/scripts/run_audit.py https://www.samsung.com --format html --out report.html
        Then show the highest-priority finding (F-001) with its evidence,
        severity, and suggested fix, and confirm findings are sorted by impact.

  3. Where the report is written and how findings appear:
        - report.json  = the canonical machine-readable audit (findings sorted
          most-actionable-first, each with id/severity/evidence/why/how_to_fix/
          confidence/impact/priority, plus the overall "score" block).
        - report.html  = the same data as a self-contained dashboard (score
          gauge, filters, page explorer) for drilling into a finding on camera.
        - Validate the schema:
          python skills/audit-orchestrator/scripts/validate_report.py report.json

  (Offline sanity checks - no network - if desired:)
        python -m unittest discover -t . -s tests      # 168 tests, OK
        python skills/audit-orchestrator/scripts/eval.py # 8/8, recall 1.00, 0 FP

    - Exit code: 0
